# g-tee-oh

A personal, self-hosted no-limit hold'em cash trainer and solver, library-first: every spot studied or trained on is served from a solutions library built in the background, so no request path ever starts a solve.

Status: sprint 1 (v1) in progress. The planning set lives in a private vault; its sanitized mirror lands under `docs/` as the sprint proceeds.

License: MIT (see `LICENSE`). The vendored engine under `crates/vendor/postflop-engine` keeps its own MIT notice.
